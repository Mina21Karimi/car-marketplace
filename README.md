# 🚗 خودرومارکت (Car Marketplace)

یک پلتفرم کامل و حرفه‌ای تحت وب برای خرید و فروش خودروهای داخلی و وارداتی، و قطعات یدکی. این پروژه با استفاده از فریم‌ورک **Django** و **Tailwind CSS** ساخته شده است.

## ✨ امکانات کلیدی
- **حساب کاربری:** ثبت‌نام، ورود، پروفایل و مدیریت تنظیمات.
- **آگهی خودرو:** ثبت آگهی با گالری تا ۷ عکس، مشخصات فنی (شاسی، رنگ، موتور، گیربکس و...)، امکان معاوضه و علامت‌گذاری «فروخته شد».
- **آگهی قطعات:** ثبت و جستجوی قطعات یدکی با شماره فنی.
- **جستجو و فیلتر پیشرفته:** فیلتر بر اساس شهر، برند، قیمت، سال ساخت و نوع گیربکس به همراه صفحه‌بندی.
- **ارتباط مستقیم:** پیام‌رسانی بین خریدار و فروشنده + پروفایل عمومی فروشنده.
- **علاقه‌مندی‌ها:** ذخیره آگهی‌ها در لیست علاقه‌مندی‌ها.
- **پشتیبانی و مشاوره:** سیستم تیکتینگ و فرم درخواست مشاوره.
- **پنل مدیریت:** داشبورد اختصاصی مدیر برای مشاهده آمار، مدیریت آگهی‌ها و گزارش‌های تخلف.
- **دو زبانه (FA/EN):** پشتیبانی کامل از فارسی (RTL) و انگلیسی (LTR).
- **تم تاریک/روشن:** با قابلیت ذخیره‌سازی ترجیح کاربر.
- **سئو (SEO):** متا تگ‌ها، نقشه سایت (Sitemap) و فایل Robots.txt.

## 🛠 تکنولوژی‌های استفاده شده
- **Backend:** Python, Django
- **Database:** PostgreSQL
- **Frontend:** HTML5, Tailwind CSS, Alpine.js, HTMX
- **Image Processing:** Pillow
- **Deployment:** WhiteNoise, Gunicorn
